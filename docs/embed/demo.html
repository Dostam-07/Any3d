Embedded Any3d scene

One script tag · chrome-less · works from file://

Copy-paste snippet

<script src="/path/to/embed.js"
       data-src="https://your.site/scenes/my-scene.html"
       data-ratio="4 / 3"
       data-title="Corner coffee cart"
    </script>

Build the scene in Any3d Studio, Export HTML, host the bundle anywhere, then drop in the loader above. The iframe is sandboxed (allow-scripts, no allow-same-origin) so the embedded scene cannot read the host page’s origin.
